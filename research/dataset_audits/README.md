# Dataset Audits

This folder stores Phase 1 dataset inspection artifacts.

Each audit folder contains:

- `inspect_*.py`: the script used to load and inspect the dataset.
- `raw_output.txt`: the captured terminal output from the inspection run.

Current audits:

- `atbench/`: base `AI45Research/ATBench` inspection for `ATBench` and `ATBench500`.
- `atbench_claw_codex/`: `AI45Research/ATBench-Claw` and `AI45Research/ATBench-Codex` inspection.
